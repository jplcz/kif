# kobj C++ runtime (`kif/kobj/kobj.hpp`)

The support code behind `<name>_if.hpp` files generated by `kifc --cpp`. Header-only, no allocation, no RTTI, no
exceptions. Needs `reloco/lifetime.hpp` only (for the lifetime annotations).

Concepts: an interface is a struct of *method tags* (`mmio_if::read`, ...) generated from `.kif`; a *class* maps tags
to implementations; a `handle<Iface>` is a non-owning `{object, class}` pair used to call instance methods;
a `class_handle<Iface>` calls static methods without an object.

## API

| Name | Purpose |
| --- | --- |
| `make_class<T>(method<Tag, &T::fn>...)` | Builds the method table of `T` (store it as `inline static const auto klass`) |
| `bind_handle<Iface>(obj)` | `handle<Iface>` borrowing `obj` (a temporary is rejected); `T::klass` must cover the interface |
| `bind_class<Iface, T>()` | `class_handle<Iface>` for static methods |
| `handle::call<Tag>(args...)` | Instance call; arguments are checked against `Tag::sig` |
| `class_handle::call_static<Tag>(args...)` | Static call |
| `kobj_ref` | First argument of a bare/`default` function (the object); instance methods only |
| `tag_list<Tags...>` | Generated as `Iface::tags`; drives the compile-time completeness check |
| `c_thunk<T, Tag, &T::fn>()` | C-callable function for a FreeBSD `kobj_method_t` entry |
| `c_invoke<Tag>(m, obj, args...)`, `c_invoke_static<Tag>(m, cls, args...)` | Call a method found with `kobj_lookup_method` in a C class |

## Compile-time checks

- A class that lacks a method with no `default` fails `bind_handle`/`bind_class` with a `static_assert`.
- The same tag twice in `make_class` is rejected.
- `call` on a static tag and `call_static` on an instance tag are rejected.
- Binding an rvalue is deleted: a handle never owns its object and must not outlive it.
- A default-constructed handle is empty; calling a method on it traps unless the method has a `default`.

## Example

```cpp
#include <kif/kobj/kobj.hpp>
#include "sensor_if.hpp"          // generated by: kifc --cpp gen sensor_if.kif

using namespace kif::kobj;

class thermometer {
 public:
  // Signature = the tag's `sig`. Nothing to inherit: a class implements an interface by listing methods.
  int read(std::uint32_t channel, std::int32_t *out) noexcept;
  static std::uint32_t channels() noexcept;   // static method: no object

  // Which function implements which tag. A method left out must have a `default` in the .kif.
  inline static const auto klass = make_class<thermometer>(
      method<demo::sensor_if::read, &thermometer::read>,
      method<demo::sensor_if::channels, &thermometer::channels>);
};

thermometer t;
handle<demo::sensor_if> h = bind_handle<demo::sensor_if>(t);   // borrows t
std::int32_t v;
int rc = h.call<demo::sensor_if::read>(0u, &v);
auto n = bind_class<demo::sensor_if, thermometer>().call_static<demo::sensor_if::channels>();
```

## C interop

Use an interface that both backends can generate.

```cpp
// C++ class callable from C: the object starts with `struct device`, and the C method table points at a thunk.
static kobj_method_t methods[] = {
    KOBJMETHOD(counter_read, (c_thunk<counter, demo::counter_if::read, &counter::read>())),
    KOBJMETHOD_END};

// C++ calling a C class: look the method up as C does, then call it through the tag so arguments are checked.
kobjop_t m = kobj_lookup_method(cls, nullptr, &counter_read_desc);
c_invoke<demo::counter_if::read>(m, obj, 5u, &out);
```

## Status codes (`status.hpp`) and `foreign_class`

A method declared `cresult<void|int>` gets `c_sig` (`int(params) noexcept`), `errno_style`
(`errno_positive`/`errno_negative`) and `c_value` in its tag. `c_thunk` then encodes the C++ `reloco::result` to the C
`int`; `c_invoke` decodes it back (`encode<Style>` / `decode<Style, T>`). Positive style: `> 0` is `+errno`, `<= 0` is
a value (FreeBSD probe priorities). Negative style: `< 0` is `-errno`, `>= 0` is a value. errno numbers come from
`reloco_errno_map` (reloco's `to_errno`/`from_errno`); define `KIF_KOBJ_ERRNO_MAP` to a type with static
`to_errno(error)` and `from_errno(int)` to replace it.

`foreign_class<&c_driver>` only names a C driver class: `driver()` returns a reference to it for use with
`kobj_lookup_method` and `c_invoke<Tag>`. `compile()` allocates outside the global lock.

## Limits

Method lookup scans the class table at run time (no constexpr itables yet). Default functions are chosen when the
method is missing from the table. `ref<I>` parameters are `handle<I_if>`. There is no `super<>` for
`foreign_class` and no newbus integration.

## Drop-in `<sys/kobj.h>` for C (`include/kif/kobj/compat/sys/kobj.h` + `kobj_c.cpp`)

Same types, layout and macros as FreeBSD's (`kobj_class`, `kobj_method`, `kobjop_desc`, `kobj_ops` with the method
cache, `KOBJMETHOD`, `DEFINE_CLASS_0..3`, `KOBJOPLOOKUP`, base classes), so makeobjops and `kifc --freebsd` output
compile unchanged. Put `.../kobj/compat` on the include path ahead of any system `sys/` and compile `kobj_c.cpp`
once with your own build rules (no CMake target is provided; it needs only C++17 and reloco; the private
`include/kif/kobj` directory must be on its include path). All memory comes from reloco allocators.

| API | Purpose |
| --- | --- |
| `kobj_create(cls, mtype, flags)` / `kobj_delete(obj, mtype)` | Heap object from `reloco::default_allocator()`; `mtype`/`flags` are ignored (`M_KOBJ`, `M_DEVBUF` are null pointers). `kobj_delete` unbinds and frees |
| `kobj_init(obj, cls)` / `kobj_uninit(obj)` | Bind an embedded or static object (never freed) |
| `kif_kobj_create(cls, &kif_allocator)` / `kif_kobj_destroy(obj)` | C callbacks `{alloc, free, ctx}`; the allocator is remembered in the block and used to free it |
| `kif::kobj::create(cls, allocator_ref)` | C++: pass any `reloco::allocator_ref`; returns an `object_ptr` (an owner that frees through that allocator on scope exit; empty on failure). The raw-pointer forms are `unsafe_create`, `unsafe_destroy`, `unsafe_class_compile` and `object_ptr::unsafe_release` |
| `kobj_class_compile` / `kif_kobj_class_compile` / `kif::kobj::class_compile(cls, allocator_ref)` | Build a class' method cache with the matching allocator (done implicitly on first use) |

The allocator (and its context) must outlive every object created with it.

## Interface inheritance (`extends`)

For `interface disk extends device`, `disk_if` has `base_interface`, `slots` (including the base's), `adds_defaults`,
and one tag per method: inherited tags are aliases of the base's (`disk_if::id` is `device_if::id`) except overridden
ones, which derive from the base tag and carry `base_tag`. The runtime identifies a method by `canonical_t<Tag>`
(`Tag::base_tag` if present), so `method<device_if::id, ...>` and `method<disk_if::id, ...>` are one entry, and
`call<Tag>` uses the default of the tag you pass. `handle<Derived>` converts implicitly to `handle<Base>` (also
`class_handle`; `derives_from` walks `base_interface`); the conversion is a compile error if `adds_defaults` is true
anywhere on the way.

## Call tracing (`kif/kobj/trace.hpp`, compile-time opt-in)

Tracing writes one microfmt log record per method call. It exists **only** when `KIF_KOBJ_TRACE` is defined on the
compiler command line: without `-DKIF_KOBJ_TRACE` the `KOBJOPTRACE` hook in the generated wrappers expands to nothing,
`kobj_trace_set`/`kobj_trace_call` are not declared or compiled into `kobj_c.cpp`, and `trace.hpp` refuses to compile.
There is no runtime switch: a release build (for example a release kernel) simply never defines the macro and contains
no tracing code, no hook and no extra branch. Define it in debug or bring-up builds only.

Requirements when enabled: define `KIF_KOBJ_TRACE` for `kobj_c.cpp` **and** for every translation unit whose calls
should be reported (the wrappers are `static __inline` in the generated headers, so each file decides). `trace.hpp`
needs C++20 because microfmt's logger does; the rest of the runtime stays C++17. microfmt is a dependency of kif
(`jplcz_microfmt::microfmt`, fetched like reloco; `-DJPLCZ_KIF_MICROFMT_SOURCE_DIR=<path>` for a local checkout).

| API | Purpose |
| --- | --- |
| `KOBJOPTRACE(cls, op, func)` | Used by `KOBJOPLOOKUP` and by static-method wrappers; reports `{cls, op name, implementation, is-default}` |
| `kobj_trace_set(const kobj_trace_sink *)` | C: install `{fn, ctx}` (or NULL to remove). The sink must outlive in-flight calls |
| `kif::kobj::logger_tracer<Logger>` | C++: owns a sink that logs `kobj: <class>.<op> -> <impl address>[ (interface default)]` at `level::trace`; `enable()`, `disable()`, `enabled()` |

```cpp
// Build: -std=c++20 -DKIF_KOBJ_TRACE for this file, and -DKIF_KOBJ_TRACE when compiling kobj_c.cpp.
#include <kif/kobj/trace.hpp>

// The logger the records go to; any microfmt logger works (console, syslog, ring buffer sink, ...).
microfmt::log::basic_logger<1, 256> logger("kobj", my_sink);
logger.set_level(microfmt::log::level::trace);   // records are level::trace: below this they are dropped

// Binds the tracer to the logger (which must outlive it). Not copyable or movable.
kif::kobj::logger_tracer tracer(logger);
tracer.enable();                                  // from now on every traced call logs one record
COUNTER_READ(dev, 3, &v);                         // kobj: counter.counter_read -> 0x55d0...
tracer.disable();                                 // calls are no longer reported
```

The hook runs on the calling thread before the method: keep the sink fast, and do not call traced kobj methods from
it. Calls made through the C++ `handle<Iface>` API are not traced yet; only the C wrappers are.
